# 소수의 성

초등학교 4학년 소수의 덧셈과 뺄셈을 배우는 한국어 타워 디펜스입니다. TypeScript·Phaser 3, PC·태블릿 브라우저의 가로 화면을 사용합니다. 전장·상점·구매 계산·성벽 합성·지도·결과 화면을 1280×800 캔버스에 통합하고 기기 크기에 맞춰 축소합니다.

## 실행

Windows에서 `게임실행.cmd`를 열고 `http://localhost:4173`으로 접속합니다. Node.js가 필요하며 실행 창을 열어 두세요. 1인 모험은 인터넷 연결 없이 실행할 수 있습니다. 회원가입·온라인 1:1 대전은 운영 Firebase 연결과 인터넷이 필요합니다. 운영 프로젝트 sosoo-defense-20261005의 Authentication·Firestore·방 목록·경기 기록 함수를 연결했습니다. 로컬 테스트 절차와 배포 안내는 [FIREBASE.md](FIREBASE.md)를 확인하세요. 태블릿은 같은 네트워크에서 `http://PC의IPv4주소:4173`으로 접속합니다. 방화벽 설정에 따라 접속이 제한될 수 있습니다.

개발용 실행은 `npm install` 후 `npm run dev`, 개발 주소는 `http://localhost:5173`입니다. 원본 코드 ZIP은 `npm run build`로 `dist`를 생성하고 실행합니다. 실행 파일 ZIP에는 `dist`가 포함됩니다.

## 구매하면서 소수 뺄셈 학습

1. 오른쪽 상점에서 타워를 선택하고 길 옆의 빈 칸을 누릅니다. 타워 간격 제한은 없고 바로 이웃한 칸에도 설치할 수 있습니다. 혼자 모험에서는 방어 시작 전에만 설치합니다. 타워 공격력을 별도로 선택하지 않습니다.
2. 실제 **보유 코인 − 타워 가격 = 남는 코인** 문제가 나옵니다. 혼자 모험은 준비 단계에서 계산하며, 1:1 대전은 계산 중에도 전투·시간·포탄·몬스터가 계속 진행됩니다.
3. 숫자판 또는 키보드로 답을 입력합니다. 정답이어야 비용을 차감하고 선택한 칸에 설치합니다.
4. 오답은 돈·배치를 유지하고 다시 풀 수 있습니다. 취소·닫기·Esc도 돈을 차감하지 않습니다. 직접 일시정지한 상태는 창을 닫아도 유지됩니다.

기본 등급은 받아내림 없는 쉬운 계산을 우선합니다. 희귀는 두 자리 소수와 받아내림, 영웅·전설은 4단계부터 세 자리 돈과 연속 받아내림을 우선 제공합니다. 단계·보유금·문제 순서에 맞춰 가격을 바꾸며 상점 카드에서 미리 확인합니다. 같은 보유금으로 취소하거나 회수 후 다시 설치해도 직전 식을 반복하지 않도록 다른 가격을 고릅니다. 가능한 가격이 하나뿐이면 그 가격을 사용합니다. 오답을 다시 풀 때는 문제와 가격을 고정하며, 설치 전에 돈·칸·해금·설치 제한을 다시 검증합니다. 1:1 대전도 호스트가 같은 생성 규칙으로 견적을 확정합니다.

모든 학습 식의 피연산자와 정답은 **0 이상 10 미만**입니다. 예: 첫 구매 `8.8 − 0.1 = 8.7`. 기본은 초반 한 자리 소수에서 두 자리 소수로 확장하며 가능한 쉬운 계산을 우선합니다. 상위 등급은 소수 자리의 받아내림과 연속 받아내림을 우선 제공합니다. 소수는 정수 천분의 일 단위로 계산하며 답을 반올림하지 않습니다.

| 단계 | 시작 코인 |
|---|---|
| 1 | 8.8 |
| 2 | 8.75 |
| 3 | 8.75 |
| 4 | 8.842 |
| 5 | 8.863 |
| 6 | 8.758 |
| 7 | 8.786 |
| 8 | 8.953 |
| 9 | 8.947 |
| 10 | 9.759 |

타워 가격도 10 미만입니다. 기본은 최대 1, 희귀는 1보다 크고 2 미만, 영웅은 2 이상 3 미만, 전설은 3 이상 4 미만으로 등급 순서를 유지합니다. 모든 타워는 다음 단계에서 이전 단계의 최고 가격보다 높은 범위를 사용합니다. 2단계 이후 기본은 단계당 0.05, 희귀·전설은 0.04, 영웅은 0.03씩 가격 범위가 올라갑니다. 범위 안에서 보유금과 문제 순서에 따라 가격을 고르므로 같은 단계에서도 다양한 식을 풉니다. 예: 기본 포탑은 2단계 0.42~0.44, 3단계 0.47~0.49, 10단계 0.82~0.84입니다. 가격 인상은 1:1 대전의 시간별 단계에도 적용합니다. 0.001은 4단계부터 돈에만 사용합니다.

총 보유금의 상한은 없습니다. 보상이 쌓여 10 이상이면 실제 보유금 중 `9 + 현재 소수 부분`만 구매 계산에 사용합니다. 예: 전체 코인이 12.5일 때 계산에 사용할 코인은 9.5입니다. 정답을 맞히면 전체 보유금에서 실제 타워 가격만 차감하고 나머지 코인은 보존합니다. 계산창에 이 관계를 안내합니다. 보상·회수의 덧셈도 결과가 10 미만일 때만 식을 표시하며, 범위를 넘으면 획득 코인만 안내합니다.

후반 보스와 영웅 체력은 최대 9.99로 조정했습니다. 몬스터의 크기·효과·학습 자릿수로 단계 난이도를 구분합니다. 벽돌·대전 블럭의 올바른 덧셈 결과도 10 미만이며, 높은 계정 레벨에서는 `9.00 − 4.78 = 4.22`처럼 소수 부분의 0을 거치는 받아내림을 학습합니다.

상점은 6개씩 두 페이지입니다. 공격력은 타입에 고정됩니다. 남은 체력보다 큰 공격은 무효이고 정확히 0일 때만 처치합니다. 예: 체력 1.55에 투석기 1.2를 쏘면 0.35, 번개탑 0.35로 마무리합니다. 같은 상황에도 여러 조합이 가능하므로 보상·별점의 최소 타격은 실제 최적 조합으로 계산합니다.

타워는 자동 공격하며 설치된 타워를 누르면 발사 ON/OFF와 회수를 선택합니다. 회수는 실제 지불한 가격을 반환합니다. 준비 중 다시 구매할 때도 새 코인 뺄셈을 풀어야 합니다. 전투 중 회수한 타워는 해당 방어가 끝날 때까지 다시 설치할 수 없습니다. 특수효과는 추가 피해를 주지 않습니다. 사거리는 일반 174(3칸), 망원 계열 232(4칸) 게임 픽셀로, 각 구간에 나눠 배치한 타워가 길을 공격할 수 있게 맞췄습니다. 사거리 안에서 피해를 줄 수 있는 몬스터를 우선하며, 모두 공격력보다 체력이 작으면 기존 초과 공격 규칙을 적용합니다. 타워를 회수하면 이웃한 타워의 열 간섭도 줄어듭니다. 성벽에는 열 간섭을 적용하지 않습니다.

## 성벽과 저장

돈 또는 숫자 벽돌을 드롭합니다. 성벽 제작에서 서로 다른 세 벽돌을 `□ + □ = □` 또는 `□ − □ = □` 슬롯에 넣습니다. 값이 맞으면 세 개를 소비해 성벽 하나를 얻습니다. 예: `0.6 + 0.7 = 1.3`, `1.31 − 0.56 = 0.75`. 잘못된 식은 재료를 소비하지 않습니다.

벽돌과 제작한 성벽은 단계 이동·재도전·새로고침에도 같은 브라우저에 보관합니다. 방어 전에 합성·설치하고, 설치한 성벽을 누른 뒤 회수해 다른 칸에 다시 놓을 수 있습니다. 다음 단계에서는 설치했던 성벽이 재고로 돌아옵니다. 성벽은 한 칸이고 파괴되지 않으며 길을 모두 막거나 몬스터를 가둘 수 없습니다. 보유 재고는 제한하지 않고 동시 설치 수만 제한합니다. 벽돌 목록은 6개씩 페이지로 표시합니다.

레벨·해금·별점·음향·난이도도 같은 브라우저에 저장됩니다. 돈과 타워 배치는 단계마다 새로 시작합니다. 이전 저장의 레벨·별점·재고는 유지합니다.

‘성벽 설치’를 선택한 뒤 맵의 칸을 누르면 설치 예정 성벽과 **노란 점선: 기존 길 / 청록 화살표: 설치 후 길**을 표시합니다. 전투 중 이미 나온 몬스터의 경로는 보라색으로 표시하며 이동 칸 수의 변화도 안내합니다. 이 동안 전투를 멈추고 ‘성벽 설치 확정’을 눌러야 재고를 사용해 배치합니다. 다른 칸을 누르면 미리보기가 바뀌며, 취소·Esc는 성벽을 소비하지 않습니다. 직접 멈춘 전투는 확정·취소 후에도 멈춘 상태를 유지합니다. 길을 모두 막거나 몬스터를 가두는 칸은 ‘설치 불가’로 표시하고 확정 버튼을 비활성화합니다. 회수한 성벽을 옮길 때도 같은 미리보기를 사용합니다.

## 난이도와 진행

메뉴 → 난이도 선택에서 연습·표준·도전을 고릅니다. 기본은 표준입니다. 방어 시작 전에 타워·성벽을 모두 회수한 상태에서 변경합니다.

| 난이도 | 1단계 타워 | 2단계 | 3~5단계 | 6~10단계 | 바늘탑 | 설치 성벽 |
|---|---|---|---|---|---|---|
| 연습 | 4 | 8 | 12 | 17 | 최대 4 | 최대 6 |
| 표준 | 3 | 6 | 10 | 14 | 최대 3 | 최대 4 |
| 도전 | 2 | 5 | 9 | 13 | 최대 2 | 최대 3 |

바늘탑은 전체 타워 수에 포함합니다. 표준 기본 이동 속도는 1단계 27 → 10단계 34.2px/s, 도전은 표준보다 12% 빠릅니다. 연습은 초반 27·후반 24px/s입니다. 몬스터 종류별 속도와 감속·기절을 추가 적용합니다.

단계당 2분의 웨이브, 12마리입니다. 첫 등장 8초, 이후 8.4초 간격입니다. 성 체력은 5개이며 몬스터가 통과할 때 하나씩 줄고, 다섯 번째 통과에서만 패배합니다. 동시에 여러 마리가 통과해도 체력은 0 아래로 내려가지 않습니다. 2분이 지나도 남은 몬스터가 있으면 ‘추가 방어’로 이어집니다. 모두 처리하고 성 체력과 학습 목표를 지키면 진급합니다. 성이 살아 있지만 목표가 남았으면 패배 대신 목표 연습 결과를 안내하고 진급·별점·보스 엔딩을 부여하지 않습니다. 발사 ON/OFF 사용 횟수 목표는 없습니다. 일시정지와 선택적인 2배속, 계산 도움말, 효과음·배경음 설정을 제공합니다.

## 학습 순서와 몬스터

각 단계는 고유한 길·바위 배치·불꽃 위치·바닥 색감을 사용합니다. 1단계 불꽃 앞뜰, 2단계 굽이진 회랑, 3단계 달빛 고갯길, 4단계 수정의 광장, 5단계 쌍둥이 보루, 6단계 돌의 나선, 7단계 세 개의 관문, 8단계 서리 뱀길, 9단계 균열의 우회로, 10단계 돌왕의 돌격로입니다. 기본 경로는 1~10단계 순서로 32·31·30·26·24·23·22·21·19·16칸으로 줄어 발사 기회가 적어집니다. 지그재그·중앙 광장 우회·큰 보루·나선형 진입·여러 관문 등 배치 전략이 달라지며, 재도전은 같은 지형을 복원합니다. 성벽으로 경로를 바꿔도 해당 단계의 불꽃까지 길을 남겨야 하고, 타워를 한 칸 이상 비워 배치하면 열 간섭이 없습니다. 1:1 대전은 기존의 일자 연결 맵을 유지합니다.

지도서 한대희(4-2) 3단원의 소수 자릿값·크기 비교·덧셈·뺄셈 순서를 10단계로 연결했습니다. 구매 뺄셈은 실제 돈과 설치 행동, 전투 뺄셈은 실제 체력 변화, 성벽 덧셈·뺄셈은 실제 벽돌 소비에 연결합니다.

| 단계 | 주요 학습 |
|---|---|
| 1 | 0.1·0.2와 한 자리 소수, 간단한 코인 뺄셈 |
| 2 | 0.01·두 자리 소수, 서로 다른 공격력 |
| 3 | 자릿값과 크기 비교, 1.2·0.25 등의 조합 |
| 4 | 돈의 0.001, 구매 뺄셈 정답 2회 |
| 5 | 단위 관계와 다양한 소수 크기 |
| 6 | 한 자리 덧셈과 받아올림, 성벽 준비 |
| 7 | 두 자리 덧셈과 받아올림, 성벽 2개 준비 |
| 8 | 1을 0.1 열 개로 바꾸어 빼기 |
| 9 | 0.1을 0.01 열 개로 바꾸어 빼기 |
| 10 | 구매·전투·성벽 소수 계산의 종합 적용 |

돌 슬라임 → 바위 갑충 → 철갑 골렘 → 수정 거인 → 고대 돌왕으로 확대됩니다. 최대 체력은 단계별 0.6 / 0.95 / 3.75 / 5.68 / 8.95 / 9.68 / 9.75 / 9.87 / 9.89 / 9.99입니다. 보스도 표시 체력을 정확히 0으로 만들어야 합니다.

## 그래픽과 조작

내장 imagegen으로 생성한 원본 PNG를 보존합니다. 새 `tower-heads-a-v1.png`·`tower-heads-b-v1.png`는 각각 3×2칸으로 총 12종 회전 포신입니다. 고정 받침대 위에서 몬스터를 조준하고 발사 반동을 표시합니다. 발사 섬광·궤적·기본/서리/번개/장거리 명중·돌 파편·충격파는 기존 효과 시트를 함께 사용합니다. 큰 공격은 전장만 짧게 흔듭니다. 6종 몬스터는 각각 걷기·피격·감속·퇴장 16프레임입니다.

입구의 보라색 소용돌이, 수호의 불꽃, 장식 횃불은 각각 3×3 시트의 9프레임을 반복 재생합니다. 원본 PNG를 수정하지 않고 돌 받침대의 기준점을 프레임별로 맞춰 흔들림을 줄였습니다. 준비 화면에서도 움직이며 일시 정지 시 함께 멈추고, 운영체제의 동작 줄이기 설정에서는 정지 그림을 사용합니다. 1:1 대전의 양쪽 불꽃에도 같은 애니메이션이 적용됩니다.

1인 모험은 공통 전장 이미지와 현재 단계 몬스터만 로드합니다. 1:1 대전은 공통 전장·일반 몬스터·돌 알을 먼저 로드하고 영웅 시트는 실제 등장할 때 불러옵니다. 초기 4종 단독 타워 원본도 프로젝트에 보존하므로 `public/assets/dungeon`에는 총 37개 원본 PNG가 있습니다. 모든 생성 프롬프트는 `prompts.json`, 새 타워 프롬프트·원본 저장 경로는 `tower-catalog-prompts.json`, 영웅 30종·걷기 120프레임은 `hero-prompts-v1.json`, 돌 알 10단계는 `egg-prompts-v1.json`, 입구·불꽃·횃불은 `ambient-prompts-v1.json`, 시작 화면·이야기·최종 보스는 `story-prompts-v1.json`, 출처는 `public/CREDITS.txt`에 있습니다. 사용자 제공 언더다크 디펜스 영상은 분위기 참고이며 해당 게임 그림을 복사하지 않았습니다.

모션 감소 설정은 화면 흔들림·반동·강한 효과를 생략하며 필수 구매 문제는 유지합니다. 키보드: 방향키·Enter로 칸 선택, 숫자·소수점·Backspace·Enter로 구매 문제 입력, Space 일시정지, F 성벽 제작, Esc 닫기. Tab과 Enter로 조작 버튼도 사용할 수 있습니다. 캔버스 UI와 별도로 화면 읽기 조작 버튼·문제 안내·게임 상태를 제공합니다.

## 검증과 배포

이미지 비용 최적화: 사용 중인 33개 원본 PNG 69.08 MiB를 투명도를 보존한 WebP 9.18 MiB로 변환해 86.7% 줄였습니다. 원본은 `public`에 보관하고 Vite의 배포 공개 폴더는 `web-public`입니다. 영웅 시트는 실제 표시 크기에 맞춰 폭 768px로 조정했고, 전장은 현재 단계에 필요한 몬스터만 사전 로드합니다. 1:1 영웅은 등장할 때 로드합니다. 이미지 주소에는 내용 해시를 붙이며 Vercel에서는 1년 캐시를 사용합니다. 그림이 바뀌면 주소도 바뀌어 새 파일을 가져옵니다. `npm run optimize:assets`가 원본 변경분만 변환하고 개발·빌드 전에 자동 실행됩니다. `node tools/check-assets.mjs`로 크기·투명도·배포 원본 제외를 검증합니다.

BGM·효과음은 Web Audio로 브라우저에서 합성하므로 외부 오디오 생성 API나 음원 파일 전송을 사용하지 않습니다. 음성 나레이션은 사용하지 않습니다. 첫 화면, 이야기, 모험, 대전, 학습지는 필요한 코드만 별도로 로드합니다. Firebase 조회·색인·정리 주기의 최적화는 [FIREBASE.md](FIREBASE.md)를 참고하세요.

`npm test`: 규칙·구매·저장·난이도·한 자리 자연수 범위·기록 증분 동기화·오디오 테스트. 세 난이도 × 10단계의 실제 코인 뺄셈 정답·준비 구매·발사 조절·합성 공략을 포함합니다. 공략은 예산·설치 제한을 지키며 방어 시작 후 추가 구매·회수·타워 이동 없이 고정 배치로 진행합니다. 학생 대상 난이도 평가는 별도로 필요합니다.

`npm run build`: TypeScript 검사와 배포용 Vite 빌드.

개발 서버를 실행한 뒤 `node tools/browser-check.cjs`로 구매 문제·오답·취소·정답 설치·전투 정지·재개·성벽·지도·저장·PC·태블릿을 확인합니다. `turret-check.cjs`, `combat-fx-check.cjs`, `difficulty-check.cjs`, `inventory-check.cjs`는 세부 검증입니다. `production-check.cjs`는 완성본의 실제 구매·전투 흐름을 확인합니다. Chromium이 없다면 `npx playwright install chromium`, 다른 실행 경로는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE`로 지정합니다.

`python tools/package-release.py`는 실행 파일 ZIP과 원본 코드 ZIP을 갱신하고 압축 무결성을 검사합니다. 원본은 `src`, 완성본은 `dist`, 화면 확인 자료는 `test-results`, 배포 파일은 상위 `output/decimal-defense`에 있습니다.

## 회원가입과 1:1 대전

메뉴의 **회원가입 · 1:1 대전**으로 이동합니다. 가입·로그인 후 중앙 방 목록에서 공개방 또는 비밀번호 방으로 참가하고 함께 준비 완료를 누릅니다. 방은 게임 시작 또는 생성 후 5분이 지나면 목록에서 사라집니다. 접속 정보는 자동 교환합니다. WebRTC로 호스트 컴퓨터에 연결하며 전투는 호스트 브라우저가 진행합니다. Firebase는 대기 방 목록과 접속 정보를 관리하고, 경기 종료 후 승·패·경험치·계정 레벨·오답 문항을 저장합니다. 대기실의 전적 · 오답 복습에서 확인할 수 있습니다. 직선 길의 양쪽 불꽃을 타워로 방어하면서, 동일한 소수 블럭 16개로 덧셈·뺄셈을 맞혀 돌 알을 성장시킵니다. 현재 알 레벨의 영웅 3종 중 하나를 골라 부화시켜 상대 불꽃을 공격합니다. 영웅은 레벨 1~10, 각 3종씩 총 30종으로 별도 생성했습니다. 기본 웨이브와 영웅이 함께 진행합니다.

Firebase를 차단한 상태의 두 브라우저 직접 대전과 종료 후 에뮬레이터 기록 저장을 확인했습니다. 기본은 같은 Wi-Fi/LAN이며 서로 다른 인터넷에는 선택 가능한 STUN 주소 보조가 있습니다. 게임 중계 서버는 구성하지 않아 네트워크에 따라 직접 연결이 제한됩니다. 호스트 창을 열어 두고 새로고침하지 마세요. Firebase 운영 프로젝트에 인증·Firestore·기록·방 목록·만료 정리 함수를 배포했습니다. 자세한 게임 규칙, 계정 연결과 배포 절차는 [FIREBASE.md](FIREBASE.md)에 있습니다.

## 몬스터 피격 뺄셈식

몬스터가 포탄에 맞으면 머리 위에 `기존 체력 − 공격력 = 남은 체력`이 뜹니다. 처치 타격도 `0.1 − 0.1 = 0.0`처럼 0까지 표시합니다. 수식은 몬스터를 따라가며 약 2.2초 동안 표시되고, 같은 몬스터가 다시 맞으면 최신 계산으로 바뀝니다. 소수 자릿수를 맞추고, 화면 가장자리에서 잘리지 않게 배치합니다. 피해가 무효인 공격은 성공한 뺄셈식으로 표시하지 않습니다.

기본값은 ON입니다. **메뉴 → 화면 · 효과음 · 배경음 → 몬스터 피격 뺄셈식**에서 ON/OFF를 바꿉니다. OFF는 떠 있던 식도 즉시 지웁니다. 설정은 같은 브라우저에 저장되며 1인 모험과 1:1 대전이 공유합니다. 대전은 상단 **설정** 또는 대기실의 **게임 설정**에서 변경할 수 있습니다. 모션 감소 설정에서도 수식은 표시합니다.

`node tools/hit-equations-check.cjs`는 실제 피격 계산, 위치·이동·가장자리, 처치, 여러 포탄의 순서, ON/OFF 즉시 반영·재접속 저장·모드 공유, PC·태블릿·모션 감소를 검증합니다.


1:1 블럭은 정답을 보장하는 `a + b = c` 세트 5개와 같은 세트에 참여하는 추가 블럭 1개로 16칸을 채워 섞습니다. 모든 블럭이 덧셈·뺄셈 조합에 참여합니다. 승리 경험치로 올라간 계정 레벨을 기준으로 계산 난이도를 정하며, 서로 다른 레벨은 낮은 쪽에 맞춥니다. 한 자리 소수 → 두 자리 소수 → 받아올림·연속 받아내림 → 0을 거치는 받아내림 순으로 확장됩니다. 학습 난이도는 경기 중 고정되고, 풀이 속도가 달라도 같은 순서의 문제판을 받습니다.

## 이야기와 시작 화면

「소수의 성: 마지막 불꽃」은 온 세상이 소수로 변한 저주에 맞서는 이야기입니다. 저주를 건 마법사가 소수 몬스터를 태어나게 해 세상을 점령하기 시작했고, 수호자는 몬스터를 막아내고 세상을 구해야 합니다.

기본 주소는 시작 화면입니다. **새게임 · 이어하기 · 1:1대전 · 설정 · 학습지 출력**을 제공합니다. 새게임은 기존 모험이 있으면 초기화 범위를 안내하고, 설정·1:1 계정 기록을 보존합니다. 이어하기는 마지막 선택한 단계와 벽돌·성벽 재고를 불러옵니다. 전장 주소는 `?mode=adventure`, 대전 주소는 `?mode=duel`입니다. 이전 저장 데이터도 호환됩니다.

오프닝 36초와 엔딩 22초는 Canvas 모션 그래픽입니다. 새 오프닝은 평화로운 세상 → 온 세상이 소수로 변하는 저주 → 저주를 건 마법사 → 소수 몬스터의 탄생 → 세상 점령을 위한 침공 → 세상을 구할 결심의 6개 장면으로 구성합니다. 게임 방법·계산 시연·식은 나오지 않습니다. 저주의 파동, 풍경의 숫자 조각 변환, 마법진의 소수 입자, 탄생하는 몬스터와 여러 깊이에서 진격하는 스프라이트를 카메라 이동·교차 전환·움직이는 한국어 타이포그래피와 함께 표시합니다. 음성 나레이션과 해당 토글은 모두 제거했고 한국어 자막·BGM·효과음·일시 정지·건너뛰기를 제공합니다. 백그라운드에서는 자동 일시 정지하며 모션 감소 설정을 존중합니다. 오프닝은 시작 화면에서 다시 볼 수 있습니다. 새 마법사·침공 배경은 내장 imagegen으로 생성했으며 프롬프트는 `public/assets/dungeon/opening-prompts-v2.json`에 있습니다.

10단계 「마지막 불꽃」의 최종 보스 **균열의 돌왕**은 체력 **9.99**이며, 별도 생성한 16프레임 스프라이트를 사용합니다. 정확히 0으로 처치하고 해당 방어·학습 목표를 달성하면 엔딩이 자동 재생됩니다. 보스를 성에 통과시키면 엔딩 조건을 달성할 수 없습니다. 클리어 후 시작 화면의 엔딩 다시 보기가 해금됩니다.

모션 연출 참고: [타이포그래피·카메라 이동·색 전환 사례](https://jasonzhu.ai/en/prompts/claude-opus-5-5/2103424524297420829). 해당 페이지의 지시문을 게임 요구사항으로 취급하지 않았으며, 이미지나 코드를 복사하지 않았습니다. 시작 화면·새 보스·오프닝과 엔딩의 그림 5개는 내장 imagegen으로 생성한 원본 PNG입니다. 정확한 프롬프트, 원본 경로와 게임 내 경로는 `public/assets/dungeon/story-prompts-v1.json`에 있습니다.

## 맞춤 학습지와 수집 영웅

시작 화면의 **학습지 출력**은 누적 오답·직접 요청한 도움말·정답을 바탕으로 20문항을 만들고 브라우저 인쇄 창을 엽니다. A4 세 쪽(문제 10개씩 두 쪽 + 암호 지도 한 쪽)이며 PDF 저장도 가능합니다. 타워 구매, 성벽 조각 합성, 몬스터 피격을 소재로 구성하고 기존 imagegen 영웅·돌 알 그림을 사용합니다. 모든 계산의 자연수 부분은 한 자리이며 0.001은 코인 문항에만 사용합니다.

소수 자릿수, 덧셈·뺄셈, 받아올림·받아내림, 연속 자리 이동, 다른 자릿수 유형으로 분류합니다. 연습이 필요한 유형에 최소 14문항을 우선 배정하고 나머지는 배운 유형을 섞습니다. 기록이 없으면 현재 모험 단계의 기본 유형으로 시작합니다. 기존 대전 저장 대기 기록과 로그인 계정의 Firebase 경기 오답을 중복 없이 가져옵니다. 이전에 저장되지 않았던 1인 모험의 오답은 복구할 수 없으며, 이번 버전부터 구매·합성 오답과 계산 도움말 사용을 누적합니다.

20개 정답을 룬 숫자로 바꾸고, 여섯 묶음의 합을 알파벳으로 바꾸면 **6자리 암호**가 됩니다. 20개 답 모두 암호에 사용합니다. **암호 입력 · 수집 몬스터**에서 해당 훈련서를 선택하고 입력합니다. 암호 정답은 화면·출력물에 표시하지 않고 훈련서별 SHA-256 해시로 확인합니다. 같은 학습지 재인쇄·재접속·동시 제출로 보상을 다시 받을 수 없습니다. 저장이 실패하면 보상을 완료 처리하지 않습니다.

보상은 기존 영웅 30종이며 레벨별 확률은 1~10 순서대로 **40%, 24%, 14%, 8%, 5%, 3.5%, 2.5%, 1.5%, 1%, 0.5%**입니다. 같은 레벨의 세 영웅은 같은 확률입니다. 중복 획득은 획득 횟수로 표시합니다. 수집 영웅과 학습 기록은 같은 브라우저에 보관하고 새게임에서도 유지합니다. 현재는 계정 간·기기 간 동기화하지 않습니다.

대전 전에 수집 영웅 하나를 선택합니다. 방을 만들거나 참가할 때 보유 목록을 전달하고, 준비하기 전까지 그 목록 안에서 변경할 수 있습니다. 대전 중 **Lv.X 소환**을 누르면 선택한 영웅을 원하는 때에 한 번 소환합니다. 기존 알 부화와 별도이며 코인·알을 소비하지 않고, 기존 가속·군집·감속 저항 효과를 그대로 적용합니다. 사용한 영웅은 수집 목록에 남고 다음 대전에서는 다시 한 번 사용할 수 있습니다. 호스트는 소유 목록에 포함된 선택, 준비 후 변경 금지, 상대 진영, 한 번 소환, 길의 몬스터 수 제한을 검증합니다. 수집 데이터는 로컬 저장이므로 서버가 인증한 경쟁 보상 시스템은 아닙니다.

추가 테스트는 `tests/worksheet.test.ts`, `tests/reserve-monster.test.ts`입니다. 생성 범위·유형 우선·20문항 암호 기여·확률·보관·중복/동시 제출·저장 실패·준비/소환 제한을 검증합니다. 실제 브라우저에서 오답/정답 보상, 여러 영웅 선택, 직접 WebRTC 연결의 양쪽 소환과 재소환 거부, PC·태블릿 시작 화면과 A4 인쇄 영역을 확인했습니다.


## 코드로 합성하는 BGM·효과음

`src/music.ts`는 시작 화면·오프닝·전투·보스전·엔딩·승리·재도전의 7개 오리지널 악보를 정의합니다. `src/audio.ts`가 Web Audio로 현악 패드·하프·종·베이스·드럼과 15가지 효과음을 합성합니다. 오디오 파일 다운로드나 외부 음향 서비스 호출은 없습니다.

브라우저의 첫 클릭 또는 키 입력 이후 재생합니다. 시작 화면·혼자 모험·1:1 화면 상단의 **배경음악 ON/OFF · 효과음 ON/OFF** 버튼으로 각각 바로 켜고 끌 수 있습니다. 설정창과도 동기화하며 같은 브라우저에서 화면 전환·새로고침 후 선택을 유지합니다. 기존 OFF 설정은 보존하고 새 브라우저의 기본값은 ON입니다. 일시정지·탭 숨김·화면 전환 시 재생을 정리합니다. 여러 타워의 동시 공격은 효과음 빈도와 음량을 제한합니다.

검증: 오디오 생명주기·개별 음소거·중복 방지·악보 유효성을 `tests/audio.test.ts`에서 검사합니다. `renderSoundtrack()`은 실시간과 같은 악기로 OfflineAudioContext 렌더링을 제공하므로 브라우저에서 음량과 클리핑을 확인할 수 있습니다.

## 배치 전략과 열 간섭

혼자 모험은 준비 단계에서 구매 계산을 풀고 전체 배치를 마친 뒤 시작합니다. 방어 시작 이후에는 일시정지하거나 타워를 회수해도 새로 설치할 수 없습니다. 1:1 대전은 전투 중에도 구매할 수 있고 문제를 열어도 호스트의 전투가 계속됩니다. 양쪽 모드 모두 설치 간격 제한은 없습니다.

모험에서 가로·세로·대각선 한 칸 이웃은 열 간섭으로 재장전 시간이 늘어납니다. 배율은 `1 + min(2, 이웃 수 × min(0.4, (단계 - 1) × 0.05))`이며 1단계는 영향이 없고 2단계부터 점차 강해집니다. 공격력과 실제 체력 뺄셈은 바뀌지 않습니다. 영향받는 타워에는 열 간섭 배율을 표시하고 선택하면 실제 재장전 시간을 보여 줍니다.

입구·중간·출구를 나눠 큰 공격과 감속/기절, 작은 나머지를 끝내는 타워를 조합합니다. 고정 배치로 10단계 × 3난이도를 통과하는 전략을 검사하고, 최종 단계에서 같은 혼합 타워의 밀집 배치 및 기본 포탑만 늘리는 배치가 실패하는 비교 검사도 수행합니다.
