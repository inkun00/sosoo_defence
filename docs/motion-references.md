## 소수 디펜스에 적용할 장면별 모션 — 설계 제안

| 상황 | 구성 | 길이·방향·색 |
| --- | --- | --- |

## 구현·검증 원칙

- 기존 게임 아트, 금속 프레임, 방패·검·별·보석 이미지를 사용하고 빛·입자·마스크·scale/opacity를 코드로 만든다. 조사한 제작자의 이미지·영상 파일은 제품 자산에 포함하지 않는다.
- 승패, 전투 시작, 모드 이동, 팝업을 서로 다른 사건으로 취급한다. 같은 이벤트가 여러 프레임에서 관측되어도 연출은 한 번만 발생한다.
- 화면 이동·나가기·재시작 때 효과와 지연 콜백을 정리한다. 새 화면에 오래된 승패 배너나 입력 차단이 남지 않는다.
- 결과창 버튼, 키보드·터치, 기존 준비/전투 시간, 저장·Firebase 기록은 시각 효과와 독립적으로 작동한다.
- 모바일 가로·세로에서 기존 게임 프레임 안에 모션을 맞춘다. 글자·클로즈 버튼을 파티클/보석이 가리지 않는다.
- `prefers-reduced-motion`에서는 새로 추가한 큰 연출과 팝업 등장 동작을 생략하고 페이지를 즉시 이동한다. 빠른 반복 점멸·지속적인 큰 화면 흔들림은 사용하지 않는다. 실제 적용 정책은 아래에 별도로 기록했다.

## 실제 적용

`src/game-motion.ts`, `src/game-motion.css` 및 모험·대전 컨트롤러와 Phaser UI 연결 코드를 읽어 확인했다. 위 표는 조사 후의 설계 제안이며, 다음 표가 최종 구현값이다.

화면 전환의 재생 속도는 기존의 **70%**로 조정했다. 공통 [screen-motion.ts](../src/screen-motion.ts)의 규칙에 따라 기존 길이와 지연을 `0.7`로 나눈다. DOM/CSS는 `cubic-bezier(.42,0,.58,1)`, 캔버스와 Phaser는 cubic ease-in-out을 사용해 천천히 출발하고 중간에 가속한 뒤 끝에서 감속한다. CSS·RAF·정리 타이머·페이지 활성화가 같은 길이를 사용한다.

모험 결과창의 별은 기존의 **실제 획득 별**을 사용한다. 약 286ms 뒤 첫 별이 찍히고 다음 별은 **약 186ms 간격**으로 등장하며, 각 별의 회전·크기 안착은 약 643ms다. 별 개수를 시각 효과를 위해 늘리거나 다시 계산하지 않는다. CPU 선택 후 도발 대기는 약 2571ms이고, 영웅 획득의 빛·마법진·등장·입자도 같은 속도와 가속·감속 규칙을 사용한다.

11단계 보스 등장과 최종 엔딩에서는 기존 시네마틱이 우선한다. 보스 진입 대사와 최종 보스를 쓰러뜨린 엔딩 위에 일반 단계 진입·승리 배너를 겹쳐 넣지 않는다.

오프닝·엔딩의 배경 전환과 제목·장식의 등장/퇴장, 보스 입장에도 공통 속도를 적용한다. 36초 오프닝·24초 엔딩의 이야기 시계와 14초 보스 대사 시계는 유지한다. 전투 종료 후의 보스 격파 연출은 프레젠테이션 시계를 0.7배로 진행해 약 8.29초 동안 재생하며, 효과음·장면·완료 판정이 같은 시계를 따른다. 모션 감소에서는 기존 동작을 유지한다.

큰 연출은 `key`로 같은 사건의 반복 재생을 막는다. 새 사건이 오면 이전 장식을 정리하고, 겹친 완료 대기도 정상적으로 끝낸다. 모션 계층은 `pointer-events: none`과 `aria-hidden="true"`이며 입력 잠금을 소유하지 않는다. 준비·전투 시계, 점수, 결과 저장은 연출과 독립적으로 진행한다.

살아 있는 게임 캔버스를 포함한 전장 요소는 등장할 때 위치를 이동하지 않고 밝기·투명도만 바꾼다. Phaser가 기억하는 입력 좌표와 실제 화면 좌표를 일치시키기 위해서다. 메뉴 버튼의 순차 등장에는 지연 구간에도 최초 프레임을 유지해 잠깐 나타났다 다시 사라지는 깜빡임을 막는다.

화면 종료 시 `pagehide`에서 큰 연출의 RAF·타이머·DOM과 패널 애니메이션을 정리한다. 페이지 이동용 성문도 `pagehide`에서 타이머와 DOM을 제거한다. 큰 연출에는 RAF가 중지되어도 장식이 남지 않도록 구현 길이+120ms의 정리 타이머가 있다.

`prefers-reduced-motion: reduce`에서는 새 큰 연출을 재생하지 않고 일반 팝업·패널의 등장 애니메이션도 생략한다. 성문을 기다리지 않고 페이지를 즉시 이동한다. 배너를 짧게 재생하거나 정지 인장으로 대체하는 정책은 실제 적용하지 않았다. 숨겨진 문서에서는 큰 연출을 생략하거나 이미 실행 중인 연출을 정리한다.
