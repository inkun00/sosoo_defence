## 발견한 문제와 수정

1. **Web Locks 미지원 환경의 동시 학습지 생성:** 동시에 만든 3장 중 마지막 1장만 저장되던 문제. 페이지 내 작업 큐로 생성·암호 제출·영웅 선택을 직렬화하고 저장 실패 뒤에도 큐가 계속 동작하도록 수정했습니다.
2. **P2P 일시 단절 복구:** 기존 데이터 채널이 열린 채로 복구되면 호스트 화면에 끊김 상태가 남던 문제. 유효한 heartbeat/state 수신 시 연결 상태를 복구하고 UI에 알립니다.
3. **두 번째 단절 안내 누락:** 복구 이후의 단절도 다시 안내하도록 알림 상태를 초기화했습니다. 연결이 끊겼을 때 화면의 몬스터 이동 예측도 중단합니다.
4. **오래된 도움말:** 전투 중 설치 문제를 푼다는 설명을 현재의 1분 준비→전투 중 즉시 설치 방식으로 수정했습니다.
5. **자산 검사 기준 누락:** 원래 41개 이미지의 7 MiB 제한에 이후 추가된 15개까지 합산해 실패했습니다. 원래 제한은 유지하고 CPU·영웅 팝업·효과 이미지에는 별도 2 MiB 제한을 적용했습니다.

추가 보완: 페이지 이동 시 소리·Peer·구독을 정리하는 앱이 BFCache로 복원되면 폐기된 런타임을 재사용할 수 있어, 캐시 복원 이벤트에서만 같은 URL을 한 번 새로고침하도록 처리했습니다. 현재 IAB의 실제 뒤로가기는 캐시 없이 다시 로드됐으며, 캐시 복원 분기는 단위 이벤트 3개로 검증했습니다.

## 검증 범위의 한계

- 실제 서로 다른 외부망, 모바일 실기기 GPU/오디오/브라우저 도구 모음 동작은 이번 브라우저 시뮬레이션으로 검증하지 않았습니다. 현재 연결은 자동 LAN/STUN 후보 선택이며 TURN 중계가 없어 일부 NAT/방화벽에서는 직접 연결이 안 될 수 있습니다.
- 일반 사용자 계정 기록을 바꾸거나 메일을 발송하지 않았습니다. 운영 경기 결과 저장, 신규 회원가입, 비밀번호 재설정 메일 발송은 실제 실행하지 않았으며 관련 모델/검증 로직만 테스트했습니다.
- Web Locks 없는 환경의 서로 다른 탭 간 동시 학습지 쓰기까지 새 큐가 직렬화하지는 않습니다.
- Vite의 기존 500 kB 이상 묶음 경고가 남습니다. 빌드 실패나 이번 실행 중 오류는 아닙니다.
