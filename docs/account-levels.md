# 1:1 계정 경험치와 레벨 배지

컴퓨터와의 대전과 플레이어 간 대전이 모두 같은 Firebase 계정 경험치에 합산된다. 기존 계정의 누적 경험치와 승패 기록은 보존하고, 누적 경험치에서 레벨을 다시 계산한다. 계정 레벨은 1~10이며 10레벨 이후에도 경험치는 쌓인다. 컴퓨터에게 이미 기록된 과거 로컬 승리는 소급 지급하지 않는다.

## 경험치

승리 기본 경험치는 `100 × 상대 레벨`이다. 1레벨 상대는 100 XP, 10레벨 상대는 1,000 XP를 지급한다. 기존 문제 보너스는 유지한다: 덧셈 정답 최대 30개와 타워 비축 문제 정답 최대 20개에 각각 5 XP를 더해, 보너스는 최대 250 XP이다. 기존 패배 기본 40 XP, 무승부 기본 60 XP, 10초 미만 경기의 0 XP 처리는 유지한다. 전투 점수와 계정 경험치는 별도 값이다.

플레이어 대전의 상대 레벨은 서버가 기존 계정 경험치로 계산한다. 최초 결과 저장 시 양측 레벨을 경기 영수증에 고정해, 어느 쪽이 먼저 저장하든 같은 기준을 사용한다. 컴퓨터 상대 레벨은 서버의 고정 상대 UID 목록에서 결정한다. 클라이언트가 보낸 임의 레벨은 보상에 사용하지 않는다.

| 레벨 | 필요한 누적 XP | 배지 |
| --- | ---: | --- |
| 1 | 0 | 단순 철제 방패 |
| 2 | 100 | 청동 방패 |
| 3 | 300 | 은빛 방패 |
| 4 | 600 | 에메랄드와 월계수 |
| 5 | 1,000 | 사파이어와 금빛 월계수 |
| 6 | 1,500 | 루비 왕관과 날개 |
| 7 | 2,100 | 자수정 왕관과 긴 날개 |
| 8 | 2,800 | 제왕의 다이아몬드 문장 |
| 9 | 3,600 | 불사조와 보석 왕관 |
| 10 | 4,500 | 다층 날개·보석 왕관·백금 문장 |

## 저장과 표시

- 두 모드의 결과를 동일한 저장 큐와 `duelSaveResult` 트랜잭션으로 처리한다. 경기 ID별로 한 번만 경험치를 지급한다.
- 연결이 끊겨도 대기 결과를 보존하고 재연결·재시도 시 저장한다. 저장 중 추가된 경기도 처리한다.
- 계정·방 전환 후 이전 요청의 응답이 새 계정이나 결과 화면을 덮어쓰지 않는다.
- 결과 화면에는 저장 전 예상 경험치, 저장 후 실제 획득 경험치, 누적 XP, 레벨업, 다음 레벨 진행도를 보여준다.
- 프로필, 컴퓨터 선택, 성 아래 이름, 결과, 기록, 명예의 전당에 계정 레벨 배지를 표시한다. 게임 진행 중인 참가자의 레벨은 해당 경기의 값으로 유지한다.
- 이전 v1 대기 기록과 계정 데이터를 그대로 읽는다. 계정 레벨은 항상 누적 경험치에서 계산하며 10을 넘기지 않는다.

## 생성 이미지

모든 배지는 OpenAI의 **내장 image_gen 도구**로 각각 생성했다. 철제 방패와 수호의 불꽃을 공통 모티프로 사용하며 레벨이 높아질수록 보석·월계수·날개·왕관을 더했다. 잘린 날개나 왕관은 같은 도구의 참조 이미지 편집으로 수정했다. 편집 가능한 원본 PNG와 투명도를 보존하며 게임에는 192px WebP 최적화본을 사용한다.

## 검증

전체 단위 테스트 627개, 실제 저장 함수와 저장 큐의 메모리 통합 시나리오 13개가 통과했다. 실제 controller를 사용한 PC 1017×884 및 모바일 390×844에서 각각 9개 흐름을 확인했다. 저장 공간 실패 뒤 재시도, 서버 보상 적용, 컴퓨터·플레이어 승리 합산, 레벨업, 중복 방지, 계정·방 전환을 포함한다. 검사 과정에서 운영 계정이나 경기 데이터를 만들지 않았다.

프로덕션 빌드, 번들 검사, 70개 이미지의 크기·투명도·해시·배포 목록 검사 및 기존 영웅 132개 프레임 검사를 통과했다. 배지 10개 원본과 최적화본의 투명도는 보존되며, 전체 배지 다운로드 예산은 256 KiB 미만이다.
