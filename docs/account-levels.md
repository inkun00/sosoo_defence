# 1:1 계정 경험치와 레벨 배지

컴퓨터와의 대전과 플레이어 간 대전이 모두 같은 Firebase 계정 경험치에 합산된다. 기존 계정의 누적 경험치와 승패 기록은 보존하고, 누적 경험치에서 레벨을 다시 계산한다. 계정 레벨은 1~50이며 50레벨 이후에도 경험치는 쌓인다. 컴퓨터 상대, 타워 학습, 전투 영웅의 레벨 범위는 기존 1~10을 유지하며 영웅 덧셈은 기존 8단계를 유지한다. 컴퓨터에게 이미 기록된 과거 로컬 승리는 소급 지급하지 않는다.

## 경험치

신규 경기의 승리 기본 경험치는 `30 × 상대 레벨`로, 이전 `100 × 상대 레벨`보다 70% 줄였다. 컴퓨터 승리에서는 보상을 받기 직전의 내 계정 레벨과 상대 레벨의 차이로 기본 경험치를 조정한다. 배율은 `clamp(20, 150, 100 + 10 × (상대 레벨 − 내 계정 레벨))%`이다. 한 레벨 높은 상대마다 10%를 더하고 한 레벨 낮은 상대마다 10%를 빼며, 최저 20%·최고 150%를 적용한다. 내 계정 Lv.5가 Lv.5 컴퓨터를 이기면 기본 150 XP, Lv.6을 이기면 198 XP, Lv.4를 이기면 108 XP이다. 플레이어 대전은 서버가 확인한 상대 계정 레벨 1~50에 `30 × 상대 레벨`을 적용하고 레벨 차이 배율은 적용하지 않는다.

문제 보너스는 덧셈 정답 최대 30개와 타워 비축 문제 정답 최대 20개에 각각 1 XP를 더한다. 이전 문항당 5 XP에서 80% 줄여 최대 50 XP를 지급한다. 패배 기본 보상은 12 XP, 무승부 기본 보상은 18 XP로 각각 70% 줄였다. 10초 미만 경기의 0 XP 처리는 유지한다. 전투 점수와 계정 경험치는 별도 값이다.

플레이어 대전의 상대 레벨은 서버가 기존 계정 경험치로 계산한다. 최초 결과 저장 시 양측 레벨을 경기 영수증에 고정해, 어느 쪽이 먼저 저장하든 같은 기준을 사용한다. 컴퓨터 상대 레벨은 서버의 고정 상대 UID 목록에서 결정하고, 내 계정 레벨은 보상 저장 직전의 서버 누적 경험치로 계산한다. 이 경기의 보상으로 레벨업하더라도 계산에는 보상을 받기 전 레벨을 사용한다. 클라이언트가 보낸 임의 레벨은 보상에 사용하지 않는다. 신규 지급은 `rewardVersion: 4`로 저장한다. 기존 누적 경험치와 과거 경기의 저장 보상은 다시 계산하지 않으며, 중복 요청은 v2·v3 보상을 포함해 처음 저장한 보상을 반환한다.

## 레벨과 배지

필요한 누적 XP는 기존과 같은 `100 × 레벨 × (레벨 − 1) ÷ 2` 곡선을 50까지 확장한다. 기존 레벨 1~10의 경계는 유지한다. 예전에 레벨 10으로 표시되던 계정에 50,000 XP가 남아 있으면 경험치를 차감하지 않고 레벨 32로 표시한다.

| 레벨 구간 | 구간 마지막 레벨의 누적 XP | 배지 모양 |
| --- | ---: | --- |
| 1~5 | 1,000 | 단순 철제 방패 |
| 6~10 | 4,500 | 청동 방패 |
| 11~15 | 10,500 | 은빛 방패 |
| 16~20 | 19,000 | 에메랄드와 월계수 |
| 21~25 | 30,000 | 사파이어와 금빛 월계수 |
| 26~30 | 43,500 | 루비 왕관과 날개 |
| 31~35 | 59,500 | 자수정 왕관과 긴 날개 |
| 36~40 | 78,000 | 제왕의 다이아몬드 문장 |
| 41~45 | 99,000 | 불사조와 보석 왕관 |
| 46~50 | 122,500 | 다층 날개·보석 왕관·백금 문장 |

배지 모양은 `ceil(계정 레벨 ÷ 5)` 단계로 선택하고 실제 계정 레벨 숫자는 별도로 표시한다. 최고 레벨 50 배지에는 금빛 광채를 더한다. 컴퓨터 상대의 레벨 표시는 기존 1~10을 유지하고 해당 레벨 구간의 배지를 사용한다.

## 저장과 표시

- 두 모드의 결과를 동일한 저장 큐와 `duelSaveResult` 트랜잭션으로 처리한다. 경기 ID별로 한 번만 경험치를 지급한다.
- 연결이 끊겨도 대기 결과를 보존하고 재연결·재시도 시 저장한다. 저장 중 추가된 경기도 처리한다.
- 계정·방 전환 후 이전 요청의 응답이 새 계정이나 결과 화면을 덮어쓰지 않는다.
- 결과 화면에는 저장 전 예상 경험치, 저장 후 실제 획득 경험치, 누적 XP, 레벨업, 다음 레벨 진행도를 보여준다.
- 프로필, 컴퓨터 선택, 성 아래 이름, 결과, 기록, 명예의 전당에 계정 레벨 배지를 표시한다. 게임 진행 중인 참가자의 레벨은 해당 경기의 값으로 유지한다.
- 이전 v1 대기 기록과 계정 데이터를 그대로 읽는다. 계정 레벨은 항상 누적 경험치에서 계산하며 50을 넘기지 않는다. 학습 문항의 레벨은 기존 1~10만 허용한다.

## 검증

레벨 확장과 보상 조정의 테스트는 1~50레벨 모든 XP 경계, 최대 정수 XP, CPU 상대 10종과 계정 레벨 50종의 배율, PvP 서버 레벨 50, 보상 직전 레벨 적용, 양측 저장 순서, v2·v3 지급 기록 중복 방지, 임의 XP·레벨 제출 거부를 포함한다. 실제 저장 함수를 메모리 Firestore로 실행해 검증하며 운영 계정이나 경기 데이터를 만들지 않는다.

보상 속도 시뮬레이션은 정답 30개·비축 10개를 풀고 계속 승리하는 조건에서 컴퓨터 Lv.1·5·10 상대를 반복한다. 계정 Lv.10에 도달하는 승리 횟수는 기존 19·7·3회에서 85·27·11회로 늘었다. CPU Lv.10 반복 시 Lv.20은 100승, Lv.50은 1,135승이 필요하다. 낮은 상대의 20% 배율까지 적용한 수치이며 실제 승패와 문제 풀이 수에 따라 진행 속도는 달라진다. 원본 코드와 결과는 검증용 `test-results/account-50/reward-pace.ts` 및 `reward-pace.json`에 저장한다. 이전 최고 레벨은 10이었으므로 Lv.20·50의 이전 대전 횟수는 같은 누적 XP 목표만 비교한다.

기존 배지 10개 원본과 최적화본의 투명도는 보존되며, 전체 배지 다운로드 예산은 256 KiB 미만이다.
