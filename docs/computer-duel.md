# 컴퓨터와 대결

1:1 메뉴에서 **컴퓨터와 대결**을 누르면 계정 로그인 후 상대 1~10단계를 선택할 수 있습니다. 전투는 브라우저에서 실행되며 컴퓨터 전적은 온라인 계정의 승패·경험치와 별도로 저장합니다.

컴퓨터는 같은 코인, 가격, 공격력, 불꽃 체력과 합성 규칙을 사용합니다. 높은 단계는 계산 시간이 짧고 다양한 타워와 영웅을 활용합니다. 큰 공격은 입구 구간에, 작은 공격은 마무리 구간에 배치합니다. 타워 뺄셈 문제는 전투 전 준비 시간에만 풉니다. 전투 중 설정과 영웅 알 합성은 기존처럼 전투를 멈추지 않습니다.

Lv.8~10은 준비 정답 뒤의 중복 대기를 줄이고 비축 타워를 전투 초반에 집중 배치합니다. 실제 코인으로 중복 타워를 교체해 감속·장거리·마무리 공격을 조합하며, 최대 타워 수는 각각 12·13·14개입니다. 영웅 알은 처음부터 목표 레벨까지 성장시켜 4분 전투 안에 해당 단계 영웅이 출전합니다. 입문 Lv.1~3의 행동 속도는 유지합니다.

상대 선택 후 시작 버튼을 누르면 수집 영웅이 있는 경우 함께 출전할 영웅을 고릅니다. 선택하면 공동 60초 문제풀이가 시작되며 수집 영웅 한 명이 즉시 등장합니다. 영웅은 준비 중 제자리에서 대기하며 전투 시작 후 움직입니다. 양쪽은 준비 예산 8.8코인으로 12종 타워 중 원하는 종류를 고르고, 가격 뺄셈을 맞힐 때마다 한 개씩 비축합니다. 오답과 취소는 예산을 차감하지 않습니다. 실제 타워 설치는 전투 시작 후 가능합니다.

영웅은 이동 가속, 체력 강화, 쉴드, 상대 포탑 감속, 내 포탑 가속 중 한 가지 효과를 갖습니다. 비율 효과는 레벨에 따라 10%~46%, 적용 반경은 2~5칸입니다. 쉴드는 공격 1회를 막고 Lv.8부터 2회를 막으며 자동 재충전하지 않습니다. 범위 밖과 영웅이 사라진 뒤에는 효과가 해제되고, 같은 효과는 가장 강한 값만 적용합니다. 컴퓨터와 플레이어는 같은 효과 규칙을 사용합니다.

60초가 끝나면 열린 문제를 닫고 양쪽 전투 코인을 0으로 초기화합니다. 전투 중 타워 선택 후 빈 칸을 누르면 비축 재고부터 무료로 배치하고, 재고가 없으면 이후 처치로 모은 코인에서 표시 가격을 즉시 차감합니다. 새 현금 구매의 타워 해금은 기존 전투 레벨을 따릅니다. 비축에는 수량 제한이 없고 실제 배치 제한 14개·바늘탑 3개는 유지됩니다. 비축 타워를 회수하면 재고로 돌아오며 코인이 생기지 않습니다. 현금 구매 타워는 실제 지불한 가격으로 환급합니다.

온라인·컴퓨터 대전 모두 양쪽 준비 완료부터 **총 5분(문제풀이 1분 + 전투 4분)**입니다. 성 파괴·기권·장시간 연결 종료로 먼저 끝나지 않으면 시간 종료 시 두 플레이어의 총점을 비교합니다. 총점이 같으면 무승부이며 남은 성 체력은 점수 판정에 사용하지 않습니다. 화면에서 전체 남은 시간과 양쪽 전투·문제 점수를 확인하고, 결과 화면에서 점수와 처치·정답 수를 비교합니다.

- 몬스터·영웅 처치마다 `100 + floor(100 / 타격 수)`점을 얻습니다. 보호막이 막은 타격도 포함하며 성에 도착한 적, 초과 공격력으로 무효가 된 공격, 단순 타격에는 점수가 없습니다.
- 준비 중 타워 구매 정답과 전투 중 영웅 소환 덧셈 정답마다 `floor(25 / (오답 횟수 + 1))`점을 얻습니다. 첫 정답은 25점, 오답 1회 후 정답은 12점, 오답 2회 후 정답은 8점입니다. 오답 25회 이상이면 정답 점수는 0이지만 타워·영웅 알은 획득합니다. 타워 문제를 취소·재선택하거나 같은 덧셈 판에서 블럭 조합을 바꿔도 누적 오답은 유지하고 정답 후 초기화합니다.
- 점수는 호스트가 계산해 참가자에게 전달하며 제한 시간 이후와 중복 정답 요청에는 추가 점수를 주지 않습니다. 이전 규칙의 클라이언트는 새 방에 참가할 수 없으므로 양쪽 모두 새로고침한 뒤 방을 만듭니다. 점수 내역은 대전과 결과 화면에 표시하며 기존 Firebase 전적 저장 형식은 유지합니다.

큰 공격력이 초기 몬스터의 남은 체력보다 크면 공격이 무효이므로 기본 포탑과 작은 공격력 타워도 함께 비축해야 처치 코인을 얻을 수 있습니다. 컴퓨터도 같은 준비 시간, 예산, 정답·재고·설치·환급 규칙을 사용합니다.

상대 선택 화면의 **대전 맵 변경**에서 좌우 대칭인 굽잇길 맵 10종을 미리 보고 고릅니다. 선택한 맵은 다음 대전에 저장되며, 진행 중인 대전의 길을 바꾸지 않습니다. 컴퓨터도 같은 길, 실제 사거리와 설치 가능한 칸을 사용합니다. 길이가 달라도 몬스터에게 주어지는 이동 시간은 같게 맞췄습니다.

## 검증

- 10명의 전체 대전, 자동 웨이브, 합성·부화·설치, 준비 타이머·정답 비축·코인 초기화·전투 즉시 설치·취소, 종료 타이머 정리를 검사합니다.
- 선택 맵 10종 × 컴퓨터 10레벨의 100대전을 시뮬레이션해 양쪽 구매, 곡선 이동, 합성·부화, 정상 종료를 검증합니다. 도로가 교차하거나 시각적 샛길을 만들지 않고, 설치 공간도 좌우 대칭임을 검사합니다.
- `tools/audit-duel-difficulty.ts`로 느린·보통·빠른 공략, 합성 속도, 타워 교체, 개인 학습 레벨, 수집 영웅과 10개 맵을 비교합니다. 느린 정상 공략은 입문 Lv.1~3을 클리어하고, 상위 상대는 부실한 방어로 빠른 합성만 반복하는 공략을 압박합니다. 실제 사거리에 맞춰 고급 타워를 교체하는 공략으로 모든 맵에서 최고 단계의 정상 승리 경로도 검증했습니다. 전후 수치와 조건은 [난이도 조정 결과](difficulty-adjustment.json)에 있습니다. 이는 가정한 자동 공략 비교이며 학생들의 실제 승률을 예측하지 않습니다.
- 이미지 검사에서 10개 시트의 투명 여백, 프레임 12개, 서로 다른 행동 이미지, 압축 크기를 확인합니다.
- 실제 브라우저에서 60초 동안 출전 영웅이 제자리에서 대기하며 정답 타워를 비축하는 흐름, 종료 시 문제 닫기와 코인 0, 비축 타워 무료 배치를 확인합니다. 실제 WebRTC 연결에서도 양쪽 startedAt가 준비 시작 정확히 60,000ms 후이며 코인이 0임을 검사합니다. 현재 1:1 메뉴는 계정 로그인이 필요합니다.
