# 컴퓨터와 대결

1:1 메뉴에서 **컴퓨터와 대결**을 누르면 계정 로그인 후 상대 1~10단계를 선택할 수 있습니다. 전투는 브라우저에서 실행되며 컴퓨터 전적은 온라인 계정의 승패·경험치와 별도로 저장합니다.

컴퓨터는 같은 코인, 가격, 공격력, 불꽃 체력과 합성 규칙을 사용합니다. 높은 단계는 계산 시간이 짧고 다양한 타워와 영웅을 활용합니다. 큰 공격은 입구 구간에, 작은 공격은 마무리 구간에 배치합니다. 타워 뺄셈 문제는 전투 전 준비 시간에만 풉니다. 전투 중 설정과 영웅 알 합성은 기존처럼 전투를 멈추지 않습니다.

상대 선택 후 **1분 준비 시작**을 누르면 공동 60초 문제풀이가 시작됩니다. 양쪽은 준비 예산 8.8코인으로 12종 타워 중 원하는 종류를 고르고, 가격 뺄셈을 맞힐 때마다 한 개씩 비축합니다. 오답과 취소는 예산을 차감하지 않습니다. 준비 중 실제 타워와 몬스터는 배치하지 않습니다.

60초가 끝나면 열린 문제를 닫고 양쪽 전투 코인을 0으로 초기화합니다. 전투 중 타워 선택 후 빈 칸을 누르면 비축 재고부터 무료로 배치하고, 재고가 없으면 이후 처치로 모은 코인에서 표시 가격을 즉시 차감합니다. 새 현금 구매의 타워 해금은 기존 전투 레벨을 따릅니다. 비축에는 수량 제한이 없고 실제 배치 제한 14개·바늘탑 3개는 유지됩니다. 비축 타워를 회수하면 재고로 돌아오며 코인이 생기지 않습니다. 현금 구매 타워는 실제 지불한 가격으로 환급합니다.

큰 공격력이 초기 몬스터의 남은 체력보다 크면 공격이 무효이므로 기본 포탑과 작은 공격력 타워도 함께 비축해야 처치 코인을 얻을 수 있습니다. 컴퓨터도 같은 준비 시간, 예산, 정답·재고·설치·환급 규칙을 사용합니다.

상대 선택 화면의 **대전 맵 변경**에서 좌우 대칭인 굽잇길 맵 10종을 미리 보고 고릅니다. 선택한 맵은 다음 대전에 저장되며, 진행 중인 대전의 길을 바꾸지 않습니다. 컴퓨터도 같은 길, 실제 사거리와 설치 가능한 칸을 사용합니다. 길이가 달라도 몬스터에게 주어지는 이동 시간은 같게 맞췄습니다.

## 검증

- 10명의 전체 대전, 자동 웨이브, 합성·부화·설치, 준비 타이머·정답 비축·코인 초기화·전투 즉시 설치·취소, 종료 타이머 정리를 검사합니다.
- 선택 맵 10종 × 컴퓨터 10레벨의 100대전을 시뮬레이션해 양쪽 구매, 곡선 이동, 합성·부화, 정상 종료를 검증합니다. 도로가 교차하거나 시각적 샛길을 만들지 않고, 설치 공간도 좌우 대칭임을 검사합니다.
- `tools/computer-duel-simulation.ts`로 같은 기준 전략을 5개 시드에서 비교했습니다. 새 준비 경제의 기준 전략은 1~4단계를 이기고 5~10단계와 비겼습니다. 더 빠른 합성과 높은 레벨의 군집 영웅을 사용하는 별도 전략도 최고 단계에서 5회 모두 비겼습니다. 이는 회귀 검증이며 학생들의 실제 승률을 예측하는 결과가 아닙니다.
- 이미지 검사에서 10개 시트의 투명 여백, 프레임 12개, 서로 다른 행동 이미지, 압축 크기를 확인합니다.
- 실제 브라우저에서 60초 동안 몬스터 없이 정답 타워만 비축하는 흐름, 종료 시 문제 닫기와 코인 0, 비축 타워 무료 배치를 확인합니다. 실제 WebRTC 연결에서도 양쪽 startedAt가 준비 시작 정확히 60,000ms 후이며 코인이 0임을 검사합니다. 현재 1:1 메뉴는 계정 로그인이 필요합니다.
