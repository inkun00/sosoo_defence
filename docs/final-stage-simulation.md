# 최종 스테이지 시뮬레이션 검증

1~11단계 × 연습·표준·도전 × 개별 시작·인벤토리 연속 보관 = 66회 성공.

실제 Defense 모델의 0.1초 프레임으로 검증한다. 실제 구매 문제에 정답을 입력해 준비 단계에서만 타워를 설치한다. 전투 중에는 타워의 발사 토글과 실제 드롭 벽돌의 합성·성벽 배치만 수행한다. 타워 추가 구매·회수·이동, 돈·체력 보정은 하지 않는다. 합법적인 배치를 최대 10개 비교하여 클리어되는 배치를 기록한다. 자동 조작 검증이며 학생의 실제 플레이 난이도 평가는 별도다.

11단계는 일반 몬스터 12마리의 기존 8.4초 간격 웨이브와 별도로 16초에 체력 99.9의 저주 마법사 한 명이 등장한다. 방어 성공과 마법사의 정확한 0 처치가 모두 필요하다. 웨이브 시간은 120초이며, 남은 몬스터가 있으면 기존 추가 방어 규칙에 따라 전투가 계속된다.

살아 있는 최종 마법사는 반경 3칸의 다른 몬스터를 강화한다. 이동 속도는 +25%이며, 감속 중 속도 계수는 0.6에서 0.8로 높아지고 기절은 2배 빠르게 회복한다. 마법사 자신은 강화하지 않으며, 범위를 벗어나거나 마법사가 죽거나 성에 도착하면 효과가 끝난다. 현재·최대 체력과 정확한 소수 뺄셈은 바꾸지 않는다. 아래 결과는 이 오라를 적용한 실제 전투 측정이다.

최종 스테이지 준비 화면 전에는 14초의 보스 대면 연출을 재생한다. 연출 중에는 Defense 모델의 전투 시간이 멈춘다. 이 시뮬레이션은 연출을 직접 재생하지 않으며, 아래 시간은 준비 조작과 연출 시간을 제외한 전투 시간이다.

최종 준비금은 19.98코인이다. 실제 구매 문항에는 기존 규칙대로 보유금의 한 자리 자연수 부분만 사용하므로 구매·벽돌 문항은 계속 10 미만이다. 99.9는 요청된 최종 보스의 전투 체력만의 예외다.
