# 최종 스테이지 시뮬레이션 검증

1~11단계 × 연습·표준·도전 × 개별 시작·인벤토리 연속 보관 = 66회. 성공 66회, 실패 0회.

tests/adventure-helpers.ts의 고정 배치를 실제 Defense 모델의 0.1초 프레임으로 재현한다. 준비 단계에서 합법적인 구매 문제를 풀어 타워를 설치하고, 전투 중에는 모든 타워가 계속 자동 공격한다. 실제 드롭·보관 벽돌의 덧셈 합성과 얻은 성벽의 길 위 배치만 수행한다. 타워 발사 전환·추가 구매·회수·이동, 돈·체력 보정과 실패 시 다른 배치 탐색은 없다. 자동 조작 검증이며 학생의 실제 플레이 난이도 평가는 별도다.

11단계는 일반 몬스터 12마리의 기존 8.4초 간격 웨이브와 별도로 16초에 체력 99.9의 저주 마법사 한 명이 등장한다. 방어 성공과 마법사의 정확한 0 처치가 모두 필요하다. 웨이브 시간은 120초이며, 남은 몬스터가 있으면 기존 추가 방어 규칙에 따라 전투가 계속된다.

마법사 자신의 생존 시간으로 3초 시전 준비 → 5초 발동 → 4초 휴식을 반복한다. 12초마다 광폭 질주(이동 속도 +25%) → 서리 파괴(감속 계수 0.6→0.8) → 불굴의 의지(기절 회복 2배) 순서로 바뀐다. 발동 중 반경 3칸의 다른 몬스터에게 해당 주문 한 가지가 적용된다. 마법사 본인, 준비·휴식 시간, 범위 밖에는 적용하지 않는다. 마법사 사망·성 도착 시 끝나며 현재·최대 체력과 소수 뺄셈은 바꾸지 않는다.

최종 준비 화면 전에는 14초의 대면 연출을 재생하고 전투 시간을 멈춘다. 이 도구는 연출을 재생하지 않으며 아래 시간은 준비 조작과 연출을 제외한 전투 시간이다. 최종 준비금은 19.98코인이다. 구매 문항은 기존처럼 보유금의 한 자리 자연수 부분만 사용하므로 10 미만이며 99.9는 최종 보스 체력의 예외다.

모든 실행의 배치, 준비 후·종료 후 코인, 재고 입출력, 성 체력, 처치·유출·학습 목표, 보스 처치 시각은 JSON에 기록한다. 주문은 실제 boss-warning/boss-cast 이벤트를 각각 집계하며, phase 전환 시각과 위치, 강화된 몬스터가 있었던 시간도 기록한다. 읽기 전용 step 관찰자는 실행 후 복원하며 전투 동작을 바꾸지 않는다.
