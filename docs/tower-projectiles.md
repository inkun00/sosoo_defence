# 타워별 발사 애니메이션

12종 모두 이름에 맞는 실루엣과 궤적을 사용합니다. 혼자 모험과 1:1 대전에 같은 렌더러를 연결했습니다.

| 타워 | 발사체와 움직임 |
|---|---|
| 기본 포탑 | 불꽃과 연기를 남기는 철포탄 |
| 쌍석포 | 65ms 간격으로 출발하는 두 개의 돌 포탄 |
| 바늘탑 | 빠르고 가는 은빛 바늘 |
| 조약돌포 | 돌 조각을 남기며 회전하는 자갈 |
| 서리탑 | 눈꽃과 고리가 도는 서리 구체 |
| 빙창탑 | 목표 방향을 유지하는 긴 얼음창 |
| 투석기 | 그림자와 함께 포물선으로 날아가는 회전 돌덩이 |
| 번개탑 | 타워부터 목표까지 이어져 깜빡이는 보라색 번개 |
| 수정포 | 반짝임을 남기는 회전 수정 |
| 망원포 | 빠르고 길며 가는 금빛 탄도 |
| 수호 대포 | 연기와 압력 고리를 남기는 무거운 불꽃 포탄 |
| 룬 쇠뇌 | 마법진과 빛의 흔적을 남기는 룬 화살 |

번개 소리는 지속되는 전기 진동과 짧은 방전음으로, 투석기는 나무 발사 장치와 바람 소리로 조정했습니다. 기존 12종 고유 효과음과 음소거 설정을 사용합니다.

## 이미지와 생성 정보

기본 내장 imagegen 도구로 6열 × 4행 투명 아틀라스 세 개를 생성했습니다. 한 종류마다 6프레임, 총 72프레임입니다.

- [돌·철 계열 원본](../public/assets/dungeon/fx-flight-stone-v1.png): 기본 포탑, 쌍석포, 바늘탑, 조약돌포.
- [얼음·투석·대포 원본](../public/assets/dungeon/fx-flight-element-v1.png): 서리탑, 빙창탑, 투석기, 수호 대포.
- [마법 계열 원본](../public/assets/dungeon/fx-flight-magic-v1.png): 번개탑, 수정포, 망원포, 룬 쇠뇌.
- [최종 생성 프롬프트와 원본 저장 경로](../public/licenses/tower-projectiles-v1-prompts.json).

원본 1536×1024 PNG의 알파를 보존합니다. 게임에는 1152×768 WebP를 사용하며, 정확한 배포 경로와 용량은 [이미지 매니페스트](../src/art-manifest.json)의 fx-flight 항목에 있습니다. 소리와 모션 계산은 브라우저에서 실행합니다.

## 동작과 검증

발사 애니메이션은 시각 효과만 담당합니다. 쌍석포도 피해와 수식 표시는 한 번이며, 번개는 목표 하나만 타격합니다. 일시정지는 이동·프레임·잔상을 함께 멈춥니다. 단계 초기화와 대전 방 이동 시 효과를 취소하고, 대전 발사 기록은 타워가 회수되어도 출발 좌표를 보관합니다. 오래된 스냅샷의 발사 기록을 다시 재생하지 않습니다.

- 전체 작업 공간 테스트 197개 통과, TypeScript 및 Vite 배포 빌드 성공.
- 공개 버튼 기반 비교 화면에서 12종 실루엣과 궤적 확인, 쌍석포 한 번 명중 확인.
- 실제 DuelScene에서 전체 12종 발사/명중 각각 12회 확인. 같은 스냅샷과 구형 revision 재전송 시 추가 0회, 타워 회수 후 12종 정상 발사, 방 비우기 후 남은 효과 0개 확인.
- 실제 모험 UI에서 구매 계산, 번개탑 설치와 전투 연결 확인. 로컬 대전 장면 검증은 Firebase 요청 없이 진행했습니다.
